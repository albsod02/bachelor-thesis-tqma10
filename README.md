This repository contains Julia code for a bachelor thesis in applied mathematics at Linköping University by Albin Söderteg. The title for the thesis is "Reconstructing bottom topographies from noisy and incomplete data" and the report can be found here: "URL".

In this project the Julia package TrixiBottomTopography.jl has been used which enables use of geographical data for the bottom topography function of the shallow water equations in 1D.
